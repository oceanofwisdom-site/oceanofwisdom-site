# Ocean of Wisdom — Website Repository

Ocean of Wisdom is a gradually expanding, multilingual knowledge and philosophy website hosted on GitHub Pages at https://www.oceanofwisdom.site/.

## Current site structure

- `index.html` — homepage
- `who-am-i.html`, `what-is-all-this.html`, `am-i-connected.html`, `i-am-that.html`, `what-is-truth.html`, `what-is-bliss.html` — six question/pillar pages
- `sanatana-dharma.html` and `sd-i18n.js` — Sanatana Dharma study page and language data
- `wisdom-of-india.html` — Indian knowledge and history
- `wisdom-feed.html` — article index
- Seven standalone article pages at the repository root
- `library/index.html` — Global Knowledge Atlas
- `calendar/index.html` — astronomical calendar research prototype
- `about.html`, `methodology.html`, `contact.html`, `search.html` — project context, research standards, public correction channel and site search
- `editorial-policy.html` — editorial, source and rights policy
- `banner.png`, `logo.png`, `logo-nav.png`, `favicon.png` — site graphics (ownership/licence review remains necessary)
- `CNAME`, `robots.txt`, `sitemap.xml` — site configuration

## Editorial and rights standard

Ocean of Wisdom aims to own its original explanations, research notes and presentation while respecting the rights of authors, translators, artists, communities and institutions.

- Write explanations in original language; do not copy distinctive expression from linked publications.
- A research link is not a reuse licence.
- Reproduce third-party text, translations, images, recordings or illustrations only when the specific item's public-domain status, licence or permission has been verified.
- Keep unverified third-party media unpublished.
- Attribute material as required by its licence and identify uncertainty in historical or cultural claims.
- Distinguish established evidence, scholarly interpretation, religious tradition, disputed claims and speculation.
- Review the individual rights and provenance of the existing graphics before claiming the entire site is rights-cleared.

See [Editorial, Sources & Rights Policy](https://www.oceanofwisdom.site/editorial-policy.html).

## Development approach

The site is a static GitHub Pages project. Preserve the existing homepage and visual identity. Make small, reviewable changes; verify internal links and interactive controls after each change; and test on Android and iOS before declaring a feature complete.

The astronomical calendar is a research prototype. Its calculations, historical ephemeris coverage and outputs require independent validation before being described as authoritative.

## Deployment

The repository is configured for GitHub Pages with the custom domain in `CNAME`. For deployment configuration, use the repository's current GitHub Pages settings rather than the generic setup instructions in older copies of this README.

## Mission

Ocean of Wisdom is a knowledge-sharing project. Its credibility depends on original work, careful sourcing, transparent uncertainty and respect for intellectual property.

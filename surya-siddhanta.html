How to read this honestly

The elongation (Moon minus Sun) and the tithi it gives are frame-independent — they do not depend on where each system puts the zodiac's zero point — so comparing them is a fair test of the Surya Siddhanta's theory against modern astronomy. The individual Sun and Moon longitudes are shown in each system's own frame (the Surya Siddhanta is sidereal; the modern figures are tropical), so a direct number-for-number match is not expected there. This engine currently covers the Sun and Moon — the heart of the panchanga. The five planets, which need the Surya Siddhanta's additional śīghra (synodic) correction, are a planned addition. The modern side uses compact low-precision formulas (good to a fraction of a degree), not a full ephemeris, so that it too runs entirely offline.
